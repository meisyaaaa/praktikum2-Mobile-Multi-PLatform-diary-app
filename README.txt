Cara menjalankan proyek:
- Buka Command Prompt/Terminal di vs code atau folder, lalu pastikan direktori berada di dalam folder diary-app dan jalankan printah: 
cd diary-app
- Ketik perintah ini untuk memulai server Metro Expo: 
npx expo start
- Buka aplikasi Expo Go di HP (pastikan HP & laptop terhubung ke Wi-Fi yang sama), lalu Scan QR Code yang muncul di terminal.   
- Tekan tombol a pada terminal jika menggunakan emulator.   
- Tekan r di terminal untuk reload, atau jalankan npx expo start -c untuk membersihkan cache
